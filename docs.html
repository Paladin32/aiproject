Arqen Era 1.1 · Documentation

Intelligence, made accessible.

Arqen is a general-purpose AI interface built to help people explore ideas, understand information, write, learn, and solve everyday problems.

What is artificial intelligence?

Artificial intelligence (AI) is a field of computing focused on building systems that can perform tasks normally associated with human intelligence. These tasks include understanding language, recognizing patterns, generating text, summarizing information, translating, and helping solve problems.

Modern conversational AI often uses a large language model (LLM). A model is trained on large collections of data to recognize patterns in language and generate a relevant response one piece at a time. It does not think or understand the world exactly like a person, and its answers can be incomplete or incorrect.

What is Arqen?

Arqen is the application and experience around an AI model. It provides a chat interface where you can select an available model, send prompts, receive responses as they are generated, and keep a history of conversations in your browser.

Ask and explore

Ask questions, learn new topics, brainstorm ideas, and work through problems.

Write and create

Draft, rewrite, summarize, translate, and develop ideas with an AI assistant.

Conversation history

Reopen, rename, and delete conversations saved locally in your browser.

Choose a model

Connect an Ollama server and select one of the language models available on it.

How does it work?

Arqen's current chat interface connects to an Ollama server that you configure in Settings. Ollama runs the language model and processes the conversation; Arqen sends the messages to that server and displays the generated answer.

Important: Arqen is not currently a model trained from scratch, and the website does not host its own AI model. You need a reachable Ollama server with at least one model installed. The model and server determine response quality, speed, and availability.

Limitations and responsible use

  • AI can produce inaccurate, outdated, or fabricated information. Check important claims.
  • Do not submit passwords, private keys, or sensitive personal information.
  • Conversation history is currently stored in this browser, not synchronized between devices.
  • Image understanding, account sign-in, and cloud-synced chat history are not currently available in this version.
  • Availability depends on your Ollama server, installed model, and internet or network connection.
